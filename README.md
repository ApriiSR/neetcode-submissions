## What is this?

[NeetCode.io](https://neetcode.io) is a coding interview preparation platform featuring curated problems, video solutions, and an in-browser code editor. This repository is automatically populated with your accepted (or all) solutions using the **GitHub Sync** feature.

---

## How GitHub Sync works

1. **Connect your GitHub account** on [neetcode.io/profile/github](https://neetcode.io/profile/github).
2. **Auto-commit** — every time you submit a solution on NeetCode, it is pushed here automatically (configurable by status).
3. **Bulk Sync** — push all your past solutions at once from the GitHub settings page.
4. **Manual sync** — from the submission history panel on any problem page, sync or remove individual submissions.

## Repository structure

```

    submission-1.<ext>   ← second submission

```

**Example:**
```
Data Structures & Algorithms/two-integer-sum/submission-0.py
Data Structures & Algorithms/binary-search/submission-0.ts
```

## Automated analysis

Every push to `main` that touches `Data Structures & Algorithms/**` runs
`scripts/analyze.py` via `.github/workflows/analyze.yml`, then commits any
new output back to `main` as a bot (`analysis/**` is excluded from the
workflow's own path filter, so that commit doesn't retrigger the workflow).

For each `submission-N.py` without a matching `analysis/<slug>/submission-N.json`,
the script computes:

- **Golf stats** (deterministic, no LLM): character count, byte count,
  non-blank line count, and Python token count (via `tokenize`, excluding
  structural tokens and comments).
- **Complexity analysis** via a single call to the Moonshot open-platform
  chat completions API (OpenAI-compatible), asking for average/worst-case
  time, space, whether correctness depends on hash-table average-case
  behavior (worst case accounts for adversarial hash collisions when
  dicts/sets are involved), a short summary, and optional style notes.

### `analysis/summary.json` contract

This is the one file the website should fetch. Shape:

```json
{
  "generated_at": "2026-08-13T20:20:50Z",
  "problems": {
    "<slug>": {
      "submissions": [
        {
          "file": "Data Structures & Algorithms/<slug>/submission-N.py",
          "slug": "<slug>",
          "solved_at": "2026-08-12T20:08:33-07:00",
          "golf": {"characters": 0, "bytes": 0, "non_blank_lines": 0, "tokens": 0},
          "complexity": {
            "time_average": "O(n)",
            "time_worst": "O(n)",
            "space": "O(n)",
            "hash_dependent": false,
            "summary": "...",
            "notes": ""
          },
          "model": "kimi-k3",
          "analyzed_at": "2026-08-13T20:20:49Z"
        }
      ]
    }
  }
}
```

If the model call fails twice in a row (invalid/unparseable JSON, network
error, etc.), `complexity` is written as `null` and an `error` field is added
to that submission's record instead — this keeps the run from blocking on a
single bad response, but the workflow run itself exits nonzero so the
failure is visible in the Actions tab.

### Setup

The workflow needs a Moonshot API key as a repository secret:

```
gh secret set MOONSHOT_API_KEY --repo ApriiSR/neetcode-submissions
```

Get a new key from the Moonshot open platform console at
[platform.moonshot.ai](https://platform.moonshot.ai/console/api-keys) (it
redirects to `platform.kimi.ai` as of August 2026).

Model: the default is `kimi-k3`, Moonshot's current flagship reasoning
model on the open platform (confirmed present in the platform docs as of
2026-08-13, alongside `kimi-k2.7-code`/`kimi-k2.6`/`kimi-k2.5`; the older
`kimi-k2` line was retired). Override it by setting the `MOONSHOT_MODEL`
repository variable (`gh variable set MOONSHOT_MODEL --repo ApriiSR/neetcode-submissions`)
or the environment variable of the same name for local runs.

### Local usage

```
python3 scripts/analyze.py --mock          # dry run, no API calls, placeholder complexity
python3 scripts/analyze.py --only is-palindrome
MOONSHOT_API_KEY=... python3 scripts/analyze.py
python3 -m unittest scripts.test_analyze -v
```
